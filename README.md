# 💰 Python Expense Tracker

A simple and efficient **command-line Python Expense Tracker** that helps users record daily expenses, analyze spending patterns, and generate summaries by **month** and **category**.

Perfect for learning:
- Python File Handling  
- CSV Data Storage  
- Pandas Data Analysis  
- CLI Application Development  
- Clean Code + Modular Structure  

---

##  Features

 Add New Expense
- Category (Food, Travel, Bills, Shopping, Other)
- Amount
- Description
- Auto-date entry

 View All Expenses
Displays all stored expenses in a clean tabular format.

Monthly Spending Summary
Groups expenses by month and shows total monthly spending.

 Category-wise Summary
Shows how much money you spent on each category.
